# Makro

Plan daily calorie and macro targets, then log meals against them. Makro estimates energy needs using the Mifflin–St Jeor equation and your activity level.

## Run locally

Open `index.html` in your browser. There is no install or build step. The page loads Tailwind CSS and Inter from external providers.

## Use the tracker

1. Enter your profile and choose a cut, maintenance, or bulk goal.
2. Pick a preset or set your own carbohydrate, protein, and fat split.
3. Log meals using the built-in food list or add a custom food.

Your profile, food log, custom foods, and notes are saved in browser storage on the device you use.
